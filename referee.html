📦 CUSTOM 3D MODELS

Want your own player and referee models on the pitch instead of the default mannequins? Create a folder called models in the same place as this page and drop in:

models/player_home.glb — home team players
models/player_away.glb — away team players
models/referee.glb — the referee

Any file you skip just falls back to the default mannequin automatically. Every model is auto-scaled to the right height and recentred so it stands properly on the pitch. This only works when the page is hosted on a real web server (e.g. GitHub Pages) — it won't work if you just double-click the file.
