Export renders every frame at 1080p (1920×1080, or 1080×1920 for 9:16) and encodes an H.264 MP4 with AAC audio, ready to upload. It takes a few times as long as the edit itself. Keep this tab open while it runs. Browsers without H.264 encoding get a WebM file recorded in real time.
